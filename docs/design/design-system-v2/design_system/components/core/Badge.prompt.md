Use `Badge` to classify a row or a person — tiers (Architect / Operator / Pilot), data freshness, counts.

```jsx
<Badge tone="accent">Architect</Badge>
<Badge tone="neutral">Operator</Badge>
<Badge tone="warning" uppercase>Stale</Badge>
```

Badges classify; they never act. If it is clickable it is a `Button`. Keep to one word where possible.
