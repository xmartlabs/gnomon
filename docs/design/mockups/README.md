# Superseded — v1 "The Ledger"

These mockups (cream paper, espresso ink, terracotta accent, Fraunces + Archivo)
were the dashboard's first visual identity. They were fully replaced in
2026-08 by the "instrument" design (blue/grey, Archivo + IBM Plex Mono, dark
mode) documented in [`../design-system.md`](../design-system.md) and sourced
from [`../design-system-v2/`](../design-system-v2/).

Kept for history only. Do not implement against these files.
